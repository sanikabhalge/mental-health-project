# MindCare Frontend

React + Vite chat app with login, signup, chat, camera/mic toggles, and risk detection UI.

## Quick Start

```bash
cd frontend/client
npm install
npm run dev
```

Open http://localhost:5173

Ensure the backend is running on port 8000 (see root [README](../../README.md)).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server (Vite) |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |
